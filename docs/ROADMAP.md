# Roadmap

## Delivered

- [x] Responsive game lobby, search and category filters.
- [x] Neon Dodge retained as a standalone game.
- [x] Snake, 2048 and Minesweeper.
- [x] Local player statistics and best scores.
- [x] JSON progress export and validated import.
- [x] Import merges records without lowering existing values.
- [x] CI smoke tests and GitHub Pages deployment workflow.

## Next improvements

- [ ] Browser end-to-end tests for game controls and data backup flows.
- [ ] Improve keyboard navigation and screen-reader support.
- [ ] Add more games after the platform tests are reliable.
- [ ] Add an optional backend only if automatic cross-device sync or shared leaderboards become a real requirement.

## Explicit non-goals for the current version

- No user accounts.
- No cloud database or automatic cross-device sync.
- No public leaderboard.
- No server-verified scores.
