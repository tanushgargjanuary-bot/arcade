# Contributing

## Scope

Keep this repository focused on small games that run in a browser. Prefer plain HTML, CSS, and JavaScript when they are sufficient.

## Before changing code

- Read the current README and inspect the existing game structure.
- Keep changes focused. Avoid unrelated refactors.
- Do not add dependencies without a clear reason.

## Validation

Before opening a pull request:

- Load the game in a modern desktop browser.
- Test keyboard controls.
- Test touch controls at a narrow viewport.
- Check the browser console for errors.
- Confirm that GitHub Pages can serve the site from the repository root.

## Pull requests

Explain the user-visible change. Include manual test steps. Keep documentation in sync with behaviour.
